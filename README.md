# IoT Network Intrusion Detection and Security Monitoring System Using Machine Learning

## Project Overview

This project develops an IoT network intrusion detection and security monitoring system using machine learning.

The system analyzes network traffic characteristics and uses a Random Forest classifier to distinguish between normal and potentially malicious IoT network behavior.

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Scapy
- SQLite
- Streamlit
- Matplotlib
- Joblib

## Dataset

N-BaIoT — Detection of IoT Botnet Attacks

Source:
UCI Machine Learning Repository

## Classification

Binary classification:

- Normal
- Attack

## Project Pipeline

Dataset → Preprocessing → Random Forest → Network Traffic → Feature Extraction → Prediction → SQLite → Streamlit Dashboard
